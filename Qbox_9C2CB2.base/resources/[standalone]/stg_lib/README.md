# stg_lib
A lightweight shared utility library for FiveM scripts (ESX, QBCore, Standalone) by STG Scripts.

💾 [Download](https://github.com/stgscripts/stg_lib/releases/latest/download/stg_lib.zip)

## Dependencies

- [ox_lib](https://github.com/overextended/ox_lib)
- [oxmysql](https://github.com/overextended/oxmysql)
